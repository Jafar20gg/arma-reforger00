# المرحلة 4: ميزات قتالية، PWA، بيانات الخرائط، وتنظيف تقني (v2.20)

## ما طلبه المالك
تطوير التطبيق في أربعة اتجاهات: (1) ميزات قتالية: تصحيح الرمي + مؤقّت سقوط + سجل مهام، (2) الرياح في الحل + أسماء Arland وKolguyev، (3) عمل دون اتصال + مشاركة برابط، (4) تنظيف تقني وتشغيل كل الاختبارات.

## ما نُفّذ

### 1) الميزات القتالية
- **تصحيح الرمي (Adjust Fire):** بطاقة جديدة في لوحة FCS. الراصد ينادي مثلاً «زد 100، يسار 20» فتُدخل القيم (أزرار سريعة ±25/±50/±100م و±10/±50 مل، أو قيم مخصصة) فيتحرك الهدف بنفس التصحيح في إطار خط الرمي ويتحدّث الحل فوراً. الحساب في `offsetTarget` (distance.ts): الإزاحة الجانبية = المدى × tan(الزاوية) بدقة، وبـ mil دائرة السلاح المختار (6400/6000). الإحداثيات تُقصّ داخل حدود الخريطة.
- **مؤقّت السقوط (Splash Timer):** زر «إطلاق!» يبدأ عدّاً تنازلياً لزمن التحليق (بدقة 0.1ث عبر performance.now)، شريط تقدّم، صافرة كل ثانية في آخر 5 ثوانٍ، ووميض «سقوط!» مع صفيرتين عند الارتطام (Web Audio — يعمل بعد أول ضغطة زر).
- **سجل مهام الرمي:** ضغطة «إطلاق!» تحفظ المهمة تلقائياً، وزر «حفظ المهمة» يدوياً. النافذة (من قائمة ⋮) تعرض: التضاريس، السلاح، الذخيرة، الحلقة، شبكتا المدفع والهدف، AZ/EL/المدى/TOF، والنداء النصي. لكل مهمة: إعادة اشتباك بنقرة (تسترجع كل شيء وتوسّط الخريطة)، نسخ النداء، حذف. مسح الكل متاح. الحد الأقصى 100 مهمة، تُحترم موافقة التخزين، وتُصدَّر/تُستورَد ضمن النسخة الاحتياطية، وتُمسح مع «مسح بيانات المستخدم» و«ضبط المصنع».

### 2) الرياح وأسماء المواقع
- **ارتفاع مصحَّح بالرياح:** صندوق الرياح كان يعطي سمتاً ومدى مصحَّحين فقط؛ الآن يعيد حل جدول الحلقة عند المدى المصحَّح ويعرض **الارتفاع وTOF اللذين يجب ضبطهما**. يبقى تقديراً استشارياً كما هو موثّق.
- **Arland:** 7 مواقع بإحداثيات أمتار اللعبة من مصدر EnfusionMapMaker (نفس مصدر قائمة Everon): قاعدة المطار، قاعدة التدريب العسكرية، بورغار، أرلفيل، المزرعة، تلة موس، تلة الإشارة.
- **Kolguyev:** 7 مستوطنات معروفة (إحداثيات مستخرجة مجتمعياً — تحتاج تحققاً داخل اللعبة): كامينسك، مينيرالي، غورشكوفو، أوغولدار، التقاطع، الفيلا، منجم زينيت. أسماء عربية مضافة للجميع.

### 3) العمل دون اتصال والمشاركة
- **PWA:** manifest + أيقونات خاصة (192/512/maskable/Apple) + Service Worker يخزّن واجهة التطبيق والبلاطات (cache-first مع حد أقصى LRU ‏2500 بلاطة)، فبعد أول زيارة متصلة يعمل التطبيق ميدانياً بلا إنترنت. نداءات API الخاصة بالذكاء الاصطناعي لا تُخزَّن أبداً. التنقّل: network-first مع رجوع للنسخة المخزّنة.
- **مشاركة المهمة برابط:** زر «مشاركة برابط» ينسخ URL يحمل المهمة كاملة في الـ hash (تضاريس/سلاح/ذخيرة/حلقة/مدفع/هدف، base64 آمن للروابط). من يفتح الرابط يسترجع نفس الإعداد. لا يُرسل شيء لأي خادم.

### 4) التنظيف التقني
- حُذفت حزم غير مستخدمة: `express`, `@types/express`, `dotenv`, `tsx`, `motion`, `@google/genai` (−134 حزمة من التثبيت).
- اختبارات leaflet الثلاثة التي «لم تُشغَّل» في التقارير السابقة تعمل الآن عبر jsdom (`// @vitest-environment jsdom` + إضافة jsdom للتطوير).
- أُصلح خطآ `strictNullChecks` في phase3Maps.test.ts.
- اختبارات جديدة: `missionTools.test.ts` (12 اختباراً: offsetTarget بالاتجاهات الأربعة ودائرتي mil، مشاركة الرابط ذهاباً وإياباً ورفض المدخلات الفاسدة، تعقيم سجل المهام).
