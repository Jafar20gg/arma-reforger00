# الخرائط بدون إنترنت + استضافة البلاطات على GitHub

## كيف تشتغل الميزة (داخل التطبيق)
قائمة ⋮ ← **الخرائط بدون إنترنت**. تختار الخريطة والطبقة والعمق (التكبير)، وتضغط تنزيل. التطبيق يحفظ الصور داخل المتصفح (Cache Storage) ويستعملها بدون اتصال. إيقاف التنزيل يحفظ اللي نزل، وإعادة الضغط تكمل الناقص. زر الحذف يمسح الطبقة.
- تحتاج فتح الموقع عبر https (GitHub Pages وVercel كلاهما https).
- الموقع المصدر للصور لازم يرسل ترويسة CORS (GitHub Pages يرسلها تلقائياً).
- التنزيل ما يحتاج موافقة "الحفظ على المتصفح": هو أمر صريح منك، والتطبيق يطلب من المتصفح حفظاً دائماً.

## الأحجام التقديرية (متوسط 28KB للبلاطة، تقدير غير مقاس)
| العمق | بلاطات لكل طبقة | الحجم التقريبي |
|---|---|---|
| 5 | 1,365 | 37 MB |
| 6 | 5,461 | 149 MB |

الطبقات المتوفرة: Everon (طبوغرافية 7، قمر صناعي 7، مرسومة 6)، Arland (7، 5، 6)، Kolguyev (7، 7). كل الطبقات حتى عمق 5 ≈ 300 MB. القياس الحقيقي يطلع من `tools/make-tiles.py` (يطبع المتوسط).

## استضافة البلاطات على GitHub (مستودع منفصل)
1. أنشئ مستودعاً جديداً اسمه مثلاً `arma-fcs-tiles` وانسخ إليه محتوى `tools/tiles-repo-template/`.
2. جهّز صورة الخريطة الكاملة (مربعة، الشمال فوق) لكل طبقة، وقطّعها:
   `pip install pillow`
   `python tools/make-tiles.py everon-topo.png --terrain everon --layer topo --max-zoom 5 --out arma-fcs-tiles`
   (كرر لكل خريطة/طبقة؛ `sat` و`drawn` للطبقات الأخرى).
3. ارفع المستودع. في Settings ← Pages اختر Source: GitHub Actions. بعد النشر يصير رابطك `https://اسمك.github.io/arma-fcs-tiles`.
4. في مستودع التطبيق: Settings ← Secrets and variables ← Actions ← Variables، أضف `VITE_TILE_HOST` = ذلك الرابط (بدون / بالنهاية). أعد النشر.
5. جرّب: افتح الخريطة، ثم الخرائط بدون إنترنت ← تنزيل.

## حدود GitHub (تحقق منها قبل الالتزام)
- موقع Pages: حتى 1 GB. المستودع يُنصح ألا يتجاوز 1 GB. الملف الواحد حتى 100 MB (بلاطاتنا صغيرة).
- حركة البيانات على Pages تقريبية 100 GB شهرياً، فلا تنشر عمق 7 لكل الطبقات (≈ 600 MB لكل طبقة) إلا بعد حساب العدد المتوقع من المستخدمين.
- توصيتي: عمق 5 للجميع، وعمق 6 للطبقات الأكثر استخداماً فقط.
- ترتيب البلاطات: x من الغرب للشرق، y من الشمال للجنوب، y=0 هو الصف الشمالي (تحقق منه بالاختبار المرفق مع السكربت).

## تنبيه الترخيص (مهم)
لا ترفع على GitHub صور خرائط تخص طرفاً آخر بدون إذنه. بلاطات Enfumap الحالية ما أكدنا ترخيصها، وأداة التقطيع لا تنسخ منه ولن أكتب أداة تنسخ بلاطاته. إن استعملتم صوراً مصدرها اللعبة نفسها فراجعوا شروط Bohemia Interactive (APL-ND / شروط الـ Workshop) وتحققوا أنها تسمح بإعادة النشر. إن لم تكونوا متأكدين فاتركوا المصدر الحالي واكتفوا بميزة التنزيل منه لجهازك.
