# تطبيق أندرويد مستقل (APK)

تطبيق عادي تنزّله وتثبّته مثل أي تطبيق. يحمل كل ملفاته بداخله، وبياناته (الإعدادات، العلامات، سجل المهام، الخرائط المنزّلة) محفوظة داخل التطبيق نفسه ومنفصلة تماماً عن المتصفح والموقع. مصادر الخرائط هي نفسها (Enfumap).

## البناء (مرة وحدة، وبعدها كلما تبي نسخة جديدة)
1. ارفع الملفات كلها إلى مستودعك على GitHub (بما فيها مجلد `.github/workflows` ومجلد `tools` ومجلد `assets`).
2. Actions ← **Build Android APK** ← Run workflow. (5-10 دقائق.)
3. حمّل التطبيق من صفحة **Releases** بالمستودع: ملف `AR-FCS-...apk` مباشرة بدون zip. (يوجد نسخة ثانية داخل Artifacts.)
4. ثبّته. أندرويد يطلب السماح بالتثبيت من مصدر غير معروف.

## التحديث بدون ما تضيع البيانات
- كل تحديث تبنيه وتثبّته **فوق** القديم من غير حذف. أندرويد يقبل التحديث لأن كل النسخ موقّعة بنفس المفتاح، والبيانات والخرائط المنزّلة تبقى.
- المفتاح ينحفظ تلقائياً في GitHub (Actions cache) من أول بناء، وفيه workflow أسبوعي صغير (Keep Android signing key alive) يمنع حذفه.
- **لا تحذف التطبيق** عشان تحدّثه: الحذف يمسح بياناته. لو اضطريت، سوّ نسخة احتياطية أول (الإعدادات ← تصدير نسخة احتياطية).
- لو انمسح المفتاح (مثلاً ما بنيت شي لشهور ولا المستودع تغيّر) أندرويد يرفض التحديث، والحل نسخة احتياطية ثم حذف وتثبيت الجديد ثم استيراد النسخة.
- لضمان دائم: خزّن مفتاح التوقيع في Settings ← Secrets ← Actions بهذي الأسماء: `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS` و`ANDROID_KEY_PASSWORD`، والـworkflow يستخدمها تلقائياً بدل المحفوظ.

## نقل بياناتك من الموقع للتطبيق
بيانات المتصفح ما تنتقل لحالها. في الموقع: الإعدادات ← نسخة احتياطية ← تصدير (ملف JSON). في التطبيق: نفس المكان ← استيراد. الخرائط المنزّلة تنزّلها من جديد داخل التطبيق (قائمة ⋮ ← الخرائط بدون إنترنت).

## مميزات التطبيق
- يفتح بدون الموقع وبدون إنترنت. الإنترنت لصور الخرائط فقط، إلا إذا نزّلتها.
- زر الرجوع: يغلق آخر نافذة مفتوحة، وإذا ما في نوافذ ينزّل التطبيق للخلفية.
- الأيقونة من `assets/icon.png`. لو تبي تغيّرها استبدل الصورة (1024×1024) وأعد البناء.
- رقم الإصدار يزيد تلقائياً مع كل بناء.

## ملاحظات
- التوقيع هنا يكفي للتثبيت المباشر. للنشر على Google Play نحتاج خطوات إضافية (حساب مطوّر وAAB).
- التطبيق المثبّت لا يستخدم service worker (ما يحتاجه)، والخرائط المنزّلة تُقرأ مباشرة.
