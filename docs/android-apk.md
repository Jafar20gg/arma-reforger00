# بناء تطبيق أندرويد (APK) من GitHub

الملف: `.github/workflows/android-apk.yml` (اسمه داخل GitHub: Build Android APK).

## الخطوات
1. ارفع المشروع (بما فيه الملف أعلاه، `capacitor.config.json`، و`package.json`) إلى مستودعك.
2. إذا عندك workflow قديم بنفس الاسم "Build Android APK" وفاشل: افتحه من تبويب Actions (رابط Workflow file بصفحة التشغيل) واحذفه، أو استبدل محتواه بهذا الملف.
3. GitHub ← تبويب Actions ← Build Android APK ← Run workflow.
4. بعد ما ينجح (حوالي 5-10 دقائق) افتح التشغيل وانزل لقسم **Artifacts** وحمّل `AR-FCS-debug-apk` (ملف zip، فيه app-debug.apk).
5. على الهاتف: فك الضغط وافتح الملف. أندرويد يطلب السماح بالتثبيت من مصدر غير معروف.

## ملاحظات
- المجلد `android/` ينولّد داخل GitHub بأمر `npx cap add android`، فلا تحتاج ترفعه.
- هذا APK تجريبي (debug) موقّع بمفتاح تجريبي: يشتغل ويتثبت، لكن ما ينفع للنشر على Google Play. للنشر نحتاج مفتاح توقيع (release) نضيفه كـ Secret.
- التطبيق ينحمّل من داخل الملف نفسه (الواجهة محفوظة)، والخرائط تحتاج إنترنت إلا إذا نزّلتها من "الخرائط بدون إنترنت".
- الأيقونة حالياً الافتراضية من Capacitor. نغيّرها بعد ما يشتغل البناء.
- الإصدار يبدأ من 1.0 (versionCode 1). عند التحديث لازم نرفع الرقم.

## التطبيق مستقل عن الموقع
- الـAPK يحمل الواجهة والحاسبة وكل الكود بداخله. يفتح ويشتغل بدون الموقع وبدون إنترنت.
- الموقع (Vercel أو GitHub Pages) ينشر لحاله من نفس الكود، وتحديثه ما يغيّر التطبيق المثبّت. لتحديث التطبيق تشغّل الـworkflow وتثبّت APK جديد.
- داخل التطبيق ما يظهر زر "تثبيت التطبيق" لأنه مثبّت أصلاً.
- الشي الوحيد اللي يحتاج إنترنت: صور الخرائط. تنزّلها مرة من "الخرائط بدون إنترنت" وبعدها تشتغل بدون اتصال.
- لو تبي الخرائط **داخل الـAPK نفسه** (بدون تنزيل): ممكن، تدخل ملفات البلاطات في البناء. حجمها تقريباً 37 ميغا لكل طبقة بعمق 5. نحتاج الصور وإذن استخدامها (انظر docs/offline-maps-github.md).
